# Gale-Shapley-Random
Performs Gale-Shapley algorithm to find stable matching on randomized preference lists and groups. Takes an input list, shuffles it, and splits it into two even sized groups. Sets preference lists to be the other group, and randomizes those too. Follow instructions to run the algorithm, which exports to a CSV file with names alphabetically ordered. If the original input list is of odd size, randomly removes one person to be unmatched each iteration but still includes their named matched with "" on the CSV file. Fun!
